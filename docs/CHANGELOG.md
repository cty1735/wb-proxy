# 更新记录 (Changelog)

本项目以 [workbuddy2api-hub](https://github.com/ardeyouxipianyi/workbuddy2api-hub) v1.7.16 为基座持续叠加改动。README 顶部的「增量功能」只列主要功能，逐条明细在这里。

| 日期 | 功能 |
| --- | --- |
| 2026-10-22 | **再更正 11-128 的触发点：DSH 真机那 5780 字系统提示里有两处，两处都得断**。上一版只断身份句，用户实测仍 400。把网关落盘的真实出站请求体切段直打 cn 上游才看清：真实整段（身份句已断）仍 400；**只把 `DeepSeek​Harness​Web​GUI` 的空格断开 → 200**；只断身份句 → 仍 400；删掉 Web GUI 段、或只发前 4451 字 → 200。单发 Web GUI 段是 200（上一版据此判它「不是触发点」，错在只测了短片段，没测「两处同时在场的组合」）。现在 `sanitize_text` 对 `powered​by​DeepSeek​Harness` 与 `DeepSeek​Harness​Web​GUI` 两处都做零宽空格断开；词组一律 `" ".join([...])` 拼，源码里不写死空格与不可见字符。回归测试改为喂真实提示（`tests/fixtures/dsh_system_prompt.txt`），并加「模式里不许出现零宽字符」的守卫 —— 中途有一次编辑把 U+200B 写进了模式本身，改写当场空转（线上表现还是 11-128）。实测：同一份真实请求体经网关 POST，重启前 400、重启后 200。 |
| 2026-10-22 | （**已被同日下面一条更正：两处词组都要断**）更正上一条并修掉根因：**11-128 只认 DSH 身份句，不认 Web GUI 段**。字符串取自 DSH 安装包原文（`app.asar` 里 `@deepseek-ai/dsh-system-prompt` 的 `harness:identity` 段，order −1000，默认开启）：`You are an AI agent powered by DeepSeek Harness.`。直打 cn 上游（system 消息 + `hi`，每个 case 连发两次、两次结论一致）：控制组 200；身份句**原文 400**；身份句 + checkout 段 + Web GUI 段 400；把身份句里的空格换成 **U+200B 零宽空格 → 200**；只换 `DeepSeek Harness` 那一处空格也 200；**单独发 Web GUI 整段其实是 200**（上一条把它当触发点是错的，而且那次「改成 harness web interface」是同字符串替换、一个字节都没改）。网关出站清洗 `sanitize_text` 现在把 `powered by DeepSeek Harness` 内部的空格换成 U+200B：字面仍是原句（零宽字符还原成空格即原文）、模型照常读，出站字节里不再有那段连续文本；DSH 不用打补丁，升级也不会丢。实测：重启网关后用真实系统提示 POST `/v1/chat/completions`（cn 出口）返回 200，此前必现 400。 |
| 2026-10-22 | 修「切到鸡蛋网关后，客户端（Hermes 等）的模型列表不更新」：客户端探网关 `/v1/models` 只给 5 秒（Hermes 快模式 1.5 秒），而鸡蛋的免费源目录要拉 40 多秒 —— `/v1/models?provider=egg` 以前会**同步**等这一轮刷新，探针每次都超时，客户端的模型清单就一直停在上一家提供商。现在目录过期时先把手上那份交出去、刷新丢到后台（冷启动本来就这么做），缓存也只留 15 秒，后台刷新一落地下一次请求就是新名单（实测：48 秒 → 30 毫秒）。另一处：面板判断「客户端配置被外部改过」改比**取值**而不是原文 —— Hermes 会自己把 `default: "x"` 重写成 `default: x`，字面一变就被判成「用户改了我们那段」，切提供商时重刷模型清单会跳过它，配置里写死的模型表就一直停在上一个提供商的目录上。 |
| 2026-10-22 | 修 **DSH 在网关里必现的 400 / code 11-128**（`Illegal API invocation from an unapproved channel`）。触发点定位到 DSH 系统提示里的 **Web GUI 段落**，逐句复现：只发身份句 `You are an AI agent powered by DeepSeek.` → 200；只发 checkout 段（`The runtime context names the DeepSeek Harness implementation checkout...`）→ 200；只发 `You are interacting with the user through the DeepSeek Harness Web GUI whose URL the runtime context names. When the user refers to "this page"... they mean this GUI.` → 400。把这段里的 `harness web interface` 换成 `harness web interface` → 200（只换 `Web GUI`、只换产品名、或把整句改短也都 200，大小写不敏感 —— 上游认的是这段文本，不是单个词）。网关在出站清洗 `sanitize_text` 里做同一处改写：**DSH 不用打补丁，升级也不会丢**，同一条 WorkBuddy 通道上的其它客户端一并覆盖。这类 400 仍保留最多 2 次重发兜底，但不再记账号失败/降温（正文里 11 与 128 之间是 **U+2011 不换行连字符**，后面还有一个 `"code":400`，所以只能按文本识别，不能 `json.loads`）。 |
| 2026-10-22 | 更正 10-21 的两条旧结论：①「DSH 系统提示开头的 `powered by DeepSeek` 被拦」不成立 —— 单独发这句是 200，真正触发的是同一提示里的 Web GUI 段（见上一条）；②当时那版「去掉 Harness 后缀」的改写其实是同字符串替换，一个字节都没改，`tests/_test_dsh_sanitize.py` 现在改为验证真正生效的 Web GUI 改写。 |
| 2026-10-22 | 修 Qoder 模型「测试时没有回答、只等到超时」：账号没有套餐额度（只剩加油包）时，上游对每个模型都回 10605 + `serviceAvailable=false`（这条队列**没有服务**，不是排到队尾），以前网关照着 `retryAfterSeconds` 一等 30~120 秒，面板 30 秒一到就成了「超时：没有完成回答」。现在把 `serviceAvailable=false` 与「真在排队」分开：前者立刻把上游原因报给客户端（套餐额度为 0 / 该区域未开通该账号），后者仍按上游建议等待重试。 |
| 2026-10-22 | 修 Trae「添加账号」在浏览器里直接失败（国内版 / 国际版都是）：面板把回调地址写成看板的 origin（用户用 http://localhost:8788 打开看板时就是 `http://localhost:8788/authorize`），而 Trae 授权页里写死了只收 `^http://127\.0\.0\.1:(\d+)/authorize$`，对不上就进 invalidUrl 分支，页面直接渲染「登录失败 / 网络错误」（国际版是 “Login Failed / Something went wrong. Try to refresh the page.”），连登录框都不出。现在回调地址一律由网关按自己的本机端口生成成 127.0.0.1 形状（localhost、局域网 IP、带 query 一律归一化），授权链接的 plugin_version / x_app_version 也对齐真实客户端（2.3.85576 / 3.3.102，版本号取本机 Trae 客户端的 iCubeLastVersion），login_trace_id 改成真实客户端那样的 UUID。 |
| 2026-10-22 | 修 Qoder 国际版与 Trae 的「浏览器登录」走错通道：同步上游 v1.7.16 时 `AccountPool.start_login()` 按 provider 分流的两行被覆盖，Qoder 拿到的是 WorkBuddy 的 workbuddy.ai 链接、Trae 拿到的是腾讯的 copilot.tencent.com 链接，浏览器授权落不到自家账号池。分流补回来后各家走自己的授权页，WorkBuddy 的登录入口不变。 |
| 2026-10-22 | 模型清单的「可用性」徽标可点开**详情弹框**：失败原因（HTTP 状态码 + 上游原文 / 超时 / 空响应）整段摊开、可复制、可就地重测，并列出测试口径、时间、耗时、首字与工具 / 推理情况。 |
| 2026-10-21 | 鸡蛋视图新增「平台账号」区：**华为云 CodeArts**（浏览器授权）与 **Cline**（设备码）登录即用，凭据自动续期，可查余额、领福利、挑模型；平台模型带前缀不撞名。修掉 Cline 少 `workos:` 前缀一律 401、CodeArts 未开通福利时甩天书、平台模型撞名被丢三处问题。 |
