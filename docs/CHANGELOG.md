# 更新记录 (Changelog)

本项目以 [workbuddy2api-hub](https://github.com/ardeyouxipianyi/workbuddy2api-hub) v1.7.16 为基座持续叠加改动。README 顶部的「增量功能」只列主要功能，逐条明细在这里。

| 日期 | 功能 |
| --- | --- |
| 2026-10-21 | 修复 DeepSeek Harness（DSH）一键配置后报 upstream 400 / code 11128：DSH 系统提示开头的 “You are an AI agent powered by DeepSeek Harness.” 会被 WorkBuddy 的渠道校验拦下。网关转发前只去掉结尾的 “ Harness”，保留 “powered by DeepSeek” 身份；正文里单独出现的 DeepSeek Harness 不受影响。 |
| 2026-10-21 | 首屏不再像卡死：面板解锁后先显示居中的 loading 遮罩，账号、最近请求等首批数据到齐才淡出；首次启动默认鸡蛋时不再先露一屏「0 积分 / 0/0 账号 / 0 个 Key」，模型清单在表内单独显示「加载中」；模型目录与设置页的配额扫描目录改为后台加载（鸡蛋首次汇总要几十秒），超过 8 秒会给「先进入面板（后台继续加载）」的出口。 |
| 2026-10-20 | 新用户开箱即用：冷启动不再为了等慢上游把第一次调用卡住二十几秒（先发内置兜底清单、真目录后台拉）；某一路上游拉挂时另一路照常在（Kilo 的目录实测要 17 秒，原来的 20 秒超时一超就只剩 Zen 那一路，而 Zen 在部分地区被按 IP 拒掉，等于「一个模型都不可用」）；启动横幅直接给出「不登录账号也能用免费模型」的 curl 示例；鸡蛋的所有出口（Zen 免费车道 / Kilo 免费池 / 自建供应商池）可以统一走一个代理槽，代理连不上自动回退直连。 |
| 2026-10-20 | 供应商池的 403 / 429 说人话：403 分三种情况（Key 类型不对 / 模型在出口所在地区不开放 / 模型只开放给 agentic harness 用），429 说明白「每个免费模型每天各 50 次、UTC 0 点重置、充 $10 提到 1000 次/天」，并给出「取消勾选改走内置免费源」的做法。 |
| 2026-10-20 | 池子挑选模型时标出「顶掉内置」：池子选中的 id 若与内置免费源（Kilo / Zen）撞了，这条模型就改走本池、内置那条不再接它（一个 id 只能有一个去处）。卡片上直接写明顶掉了几个，免得把不用 Key 也能用的免费模型弄没了。 |
| 2026-10-20 | 修 Qoder / Trae 流式读取「攒满 64KB 才发」：上游排队（10605 RESOURCE_LIMIT）时 0.2 秒就把错误信封送来，却要等连接断开（实测 3 分钟）才看得见，客户端干等三分钟才报错。改用 read1() 后 0.3 秒就把上游的 403 报出去，正常流式也不再等到攒够 64KB 才吐第一个字。 |
| 2026-10-20 | 自建供应商池新增「测试」：真发一次最小请求，确认这把 Key 能不能推理（拉得到模型目录 ≠ Key 能用 —— OpenRouter 的目录是公开的，垃圾 Key 也拉得到 470 个模型）。池子报错也改口径：说清是哪个池子拒的，并给出「管理/置备 Key 不能用于推理」这类可照着改的提示。 |
| 2026-10-20 | 挑选模型支持筛选：可按模型 ID 搜索，或勾「只看免费」把上游标 `:free` / `/free` 的免费模型（OpenRouter 那 470 个里有 18 个）筛出来，免费条目还带「免费」标签；筛选后「全选」只作用于当前看得见的那些。 |
| 2026-10-20 | 鸡蛋的池子筛选按池子分开列：自建池（如 OpenRouter）与内置免费源各占一项，每项带池子名、模型数与模型名（选中后说明行摊开该池的模型）。同名模型归自建池（请求本来就走它）；自建池里只有付费的模型标「按供应商计费」，上游明确免费的（`:free`）仍标「免费」。 |
| 2026-10-20 | 客户端模型名后的来源标签按当前提供商显示：WorkBuddy 挂 `wb`、Qoder 挂 `qoder`、Trae 挂 `trae`；选中鸡蛋时按免费源细分（`kilo` / `opencode-zen`），自建供应商池用池子名。一键配置的模型规格也改为按本次 apply 的提供商取。 |
| 2026-10-20 | 鸡蛋支持添加多个供应商：每个供应商是一个池子（OpenAI / Anthropic 兼容），可拉取模型清单、挑选模型、启停与增删；模型清单新增按池子筛选，池子的模型并入 `/v1/models`。 |
| 2026-10-20 | 网关模型清单新增「免费池」列：鸡蛋视图下逐行标出该模型走的是 OpenCode Zen 免费车道还是 Kilo 免费池；数据看板的提供商筛选新增「鸡蛋」，可单独看免费网关的调用量（成功与失败都记在「鸡蛋（免账号）」这一行）。 |
| 2026-10-20 | 新增「鸡蛋」免费网关：聚合 OpenCode Zen 免费车道与 Kilo 免费池，免账号/免密钥；切换即自动刷新免费清单，看板新增免费模型概览与源状态。 |
| 2026-10-20 | 修复 v1.7.16 同步后的路由错位：`/v1/chat/completions`、`/v1/completions` 误走 Anthropic Messages 管线而返回 `message` 结构；`/v1/messages` 未转发 `?provider=`，Qoder / Trae / 鸡蛋提示被忽略。 |
| 2026-10-20 | 账号列表自适应：宽屏铺满、窄屏自动切卡片、操作按钮可换行，移除横向滚动；修复按钮文案与手机顶部出口溢出。 |
| 2026-10-20 | 同步上游 v1.7.6–v1.7.16：后台模型别名、Anthropic 图片工具结果、身份对齐、403 停止换号、账号禁用模型、Key 并发/定址、模型限额与探针、免费额度回落、401 刷新、Web 日志、多主题；保留 Qoder/Trae。 |
| 2026-10-19 | 顶部提供商切换同步账号、用量、模型清单与未绑定 Key；修复空时序图悬停报错。 |
| 2026-10-18 | 看板 KPI 可展开按账号/模型明细并修正成功率；新增实时状态、轮询、键盘读数与减弱动画。 |
| 2026-10-18 | 免费模型不计积分与等价花费；任务与福利新增“今日新增积分”和按天明细。 |
| 2026-10-18 | 新增 Trae 国际/国内提供商，支持 OAuth、本机登录态/JWT 兜底、国内自动签到、额度计费与用量分账。 |
