# 更新记录 (Changelog)

本项目以 [workbuddy2api-hub](https://github.com/ardeyouxipianyi/workbuddy2api-hub) v1.7.16 为基座持续叠加改动。README 顶部的「增量功能」只列主要功能，逐条明细在这里。

| 日期 | 功能 |
| --- | --- |
| 2026-10-22 | 鸡蛋视图新增 **Freebuff 平台账号池** 卡片：浏览器授权登录，按账号拉模型目录，模型 id 带 `freebuff/` 前缀；聊天按 CLI 协议走（先开会话再用目录 handle），设备签名用 Ed25519。修掉签名分隔符写错、首次聊天未拉目录、handle 轮换后旧会话被复用三处问题。 |
| 2026-10-22 | 修 Qoder 国际版与 Trae 的「浏览器登录」走错通道：同步上游 v1.7.16 时 `AccountPool.start_login()` 按 provider 分流的两行被覆盖，Qoder 拿到的是 WorkBuddy 的 workbuddy.ai 链接、Trae 拿到的是腾讯的 copilot.tencent.com 链接，浏览器授权落不到自家账号池。分流补回来后各家走自己的授权页，WorkBuddy 的登录入口不变。 |
| 2026-10-22 | 模型清单的「可用性」徽标可点开**详情弹框**：失败原因（HTTP 状态码 + 上游原文 / 超时 / 空响应）整段摊开、可复制、可就地重测，并列出测试口径、时间、耗时、首字与工具 / 推理情况。 |
| 2026-10-21 | 鸡蛋视图新增「平台账号」区：**华为云 CodeArts**（浏览器授权）与 **Cline**（设备码）登录即用，凭据自动续期，可查余额、领福利、挑模型；平台模型带前缀不撞名。修掉 Cline 少 `workos:` 前缀一律 401、CodeArts 未开通福利时甩天书、平台模型撞名被丢三处问题。 |
| 2026-10-21 | 网关模型清单每行新增「测试」与「启用」：测试真发一条请求到网关自己的 `/v1/chat/completions`（Agent / 对话两种口径），结论写在行内；启用开关写进 `settings.json` 的 `disabled_models`，停用后 `/v1/models` 不再返回该模型，直接调用被 400 拒绝。 |
| 2026-10-21 | 网关模型清单新增**「可用性」列**与**「一键测试模型」**：绿=可用、红=不可用、琥珀=测试中、灰=未测；批量测试 4 条并发、单条 30 秒超时，可随时「停止测试」。测过的结论记在本机，24 小时内有效。 |
| 2026-10-21 | 网关模型清单的**列头固定**：表格外面套一层自己的滚动区（限高 72vh），表头吸在滚动区上沿，滚到下面仍对得上号。 |
| 2026-10-21 | 出口（国内 / 国际）也按各家自己的走：以前不管走哪家都用全局的「当前出口」，面板停在 WorkBuddy 国内版时 Qoder 的模型会按国内版找账号，每个都 503。显式 `?realm=` / `X-Realm` / Key 绑定的出口仍然最高优先。 |
| 2026-10-21 | 四个网关（WorkBuddy / Qoder / Trae / 鸡蛋）彻底隔离，模型和请求互不影响：归属按固定顺序判定（WorkBuddy → Qoder → Trae → 鸡蛋），一个 id 只属于一家，跨家同名归第一家；显式 `?provider=` / `X-Provider` 仍然最高优先。 |
| 2026-10-21 | 上游在 200 的流里回错误时，客户端看到的是错误而不是「流没有 finish_reason」：错误事件带着上游的真实原因发给客户端，流里补一个 finish_reason 收尾块，非流式直返 502，用量记为失败。 |
| 2026-10-21 | 「全部提供商」把本机没走网关的会话也算进来：这一格 = 经本网关的请求 + 本机各客户端自己记录的会话（本地口径固定排除经网关的部分，两边天然不重复），KPI、时序、明细与最近请求都按合并后的数据画。 |
| 2026-10-21 | 数据看板新增「客户端筛选」：按已一键配置本网关的 AI 客户端（DSH / Hermes / OpenCode 等）查看 KPI、曲线、明细与最近请求；本地口径下同样按本机会话记录里的客户端筛。 |
| 2026-10-21 | 看板的「提供商筛选」新增 **本地** 一项：统计本机 OpenCode / Claude Code / Codex 自己的会话用量，并排除经本网关的请求（避免同一笔记两次）；账号池专属区块在该口径下收起。 |
| 2026-10-21 | 修复 DeepSeek Harness（DSH）一键配置后报 upstream 400 / code 11128：DSH 系统提示里的 “powered by DeepSeek Harness” 会被渠道校验拦下，转发前只去掉结尾的 “Harness”。 |
| 2026-10-21 | 首屏不再像卡死：面板解锁后先显示居中的 loading 遮罩，首批数据到齐才淡出；首次启动默认鸡蛋时不再先露一屏「积分 0 / 0 账号 / 0 Key」。 |
| 2026-10-20 | 新用户开箱即用：冷启动不再为了等慢上游把第一次调用卡住二十几秒（先发内置兜底清单、真目录后台拉）；某一路上游拉挂时另一路照常在；启动横幅直接给出不登录账号也能用免费模型的 curl 示例；鸡蛋的出口可以统一走代理槽。 |
| 2026-10-20 | 供应商池的 403 / 429 说人话：403 分三种情况（Key 类型不对 / 模型在出口所在地区不开放 / 模型只开放给 agentic harness 用），429 说明白「每模型每天 50 次、UTC 0 点重置」并给出改用内置免费源的做法。 |
| 2026-10-20 | 池子挑选模型时标出「顶掉内置」：池子选中的 id 若与内置免费源（Kilo / Zen）撞了，这条模型就改走本池、内置那条不再接它；取消勾选即还给内置源。 |
| 2026-10-20 | 修 Qoder / Trae 流式读取「攒满 64KB 才发」：上游排队（10605 RESOURCE_LIMIT）时 0.2 秒就把错误送来，却要等连接断开才看得见；改用 read1() 后 0.3 秒就把上游的 403 报出去。 |
| 2026-10-20 | 自建供应商池新增「测试」：真发一次最小请求，确认这把 Key 能不能推理（拉得到模型目录 ≠ Key 能用）。 |
| 2026-10-20 | 挑选模型支持筛选：可按模型 ID 搜索，或勾「只看免费」把上游标 `:free` / `/free` 的模型筛出来。 |
| 2026-10-20 | 鸡蛋的池子筛选按池子分开列：自建池与内置免费源各占一项，每项带池子名、模型数与模型名。 |
| 2026-10-20 | 客户端模型名后的来源标签按当前提供商显示：WorkBuddy 挂 `wb`、Qoder 挂 `qoder`、Trae 挂 `trae`；选中鸡蛋时按免费源细分。 |
| 2026-10-20 | 鸡蛋支持添加多个供应商：每个供应商是一个池子（OpenAI / Anthropic 兼容），可拉取模型清单、挑选模型、启停与增删。 |
| 2026-10-20 | 网关模型清单新增「免费池」列：鸡蛋视图下逐行标出该模型走的是 OpenCode Zen 免费车道还是 Kilo 免费池。 |
| 2026-10-20 | 新增「鸡蛋」免费网关：聚合 OpenCode Zen 免费车道与 Kilo 免费池，免账号 / 免密钥；切换即自动刷新免费清单。 |
| 2026-10-20 | 修复 v1.7.16 同步后的路由错位：`/v1/chat/completions`、`/v1/completions` 误走 Anthropic Messages 管线；`/v1/messages` 未转发 `?provider=`，Qoder / Trae 提示被忽略。 |
| 2026-10-20 | 账号列表自适应：宽屏铺满、窄屏自动切卡片、操作按钮可换行，移除横向滚动；修复按钮文案与手机顶部出口溢出。 |
| 2026-10-20 | 同步上游 v1.7.6–v1.7.16：后台模型别名、Anthropic 图片工具结果、身份对齐、403 停止换号、账号禁用模型、Key 并发 / 定址、模型限额与探针、免费额度回落、401 刷新、Web 日志、多主题；保留 Qoder / Trae。 |
| 2026-10-19 | 顶部提供商切换同步账号、用量、模型清单与未绑定 Key；修复空时序图悬停报错。 |
